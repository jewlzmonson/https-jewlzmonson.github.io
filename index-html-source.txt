            <div class="project-image"><div>Reseller Access Governance &amp; Org-Mapping Toolkit</div></div>
            <div class="project-body">
              <p class="project-meta">PROFESSIONAL WORK · PYTHON, PANDAS, DATA VISUALIZATION, PROCESS DESIGN</p>
              <h3>Turning an ad hoc access review into a repeatable, auditable pipeline</h3>
              <p>
                A large B2B sales organization managed reseller console access through a manual, ticket-based process, with approvals and removals scattered across disconnected spreadsheets and ticketing exports. That made a basic question — <em>who currently has access, and why?</em> — surprisingly hard to answer. I built an end-to-end review pipeline and a self-service routing guide to fix it.
              </p>
              <ul>
                <li><strong>Access request analysis pipeline.</strong> Cleaned and consolidated multiple raw exports — access request logs, change tickets, rep directories — into a single analyzable dataset, normalizing names, emails, dates, and request statuses across inconsistent source schemas.</li>
                <li><strong>Email-domain clustering &amp; volume breakdown.</strong> Grouped tens of thousands of data points by email domain as a proxy for organization, then visualized request volume, unique requester counts, and distinct email counts per domain over a rolling multi-month window — surfacing which populations were driving the most access traffic.</li>
                <li><strong>Org-hierarchy reconstruction from partial data.</strong> Rebuilt a three-tier reporting tree (senior manager → line manager → individual rep) from an incomplete source system, explicitly flagging how many reporting paths were recoverable, how many manager groups had no path at all, and how many individuals fell into an "unmatched / needs manual follow-up" bucket.</li>
                <li><strong>Self-service routing guide.</strong> Designed a lightweight internal HTML page letting support agents look up, by account type and request type, exactly which team owns a given change request — including a decision tree and copy-paste response templates.</li>
              </ul>

              <div class="callout">
                <strong>A deliberate design choice:</strong> show your work, flag the gaps. It is more useful to a compliance reviewer to know <em>what's unknown</em> than to silently fill missing structure with assumptions — so the hierarchy output reports its own coverage rather than presenting a clean but fictional tree.
              </div>

              <p style="margin-top:1rem;"><strong>Impact.</strong> Turned a vague audit into a concrete, prioritized to-do list — the pipeline is repeatable and auditable, and it reports exactly how much of the hierarchy could be verified automatically versus needed manual follow-up. Support staff got a single source of truth for routing, cutting misrouted tickets.</p>

              <h3>COVID-19 Vaccination &amp; Mortality Analysis</h3>
              <p>
                Used SQL to clean and join global COVID-19 death and vaccination datasets, then built an interactive Tableau dashboard to explore how vaccination rollout related to shifts in death rates across countries and time periods, complemented by original primary survey data collected via Qualtrics.

              <ul>
                <li>Segmented the data into Pre-Vaccination (2020), Early Vaccination (2021), and Expanded Vaccination (2022+) eras using CASE statements — case fatality rates dropped in 4 of 5 countries after rollout (India: 1.45% → 0.71%, China: 4.99% → 0.96%)</li>
                <li>Used CTEs and window functions to build cumulative vaccination rollout by country, a 7-day rolling average to smooth reporting spikes, and RANK() to compare deaths per 100,000</li>
                <li>Collected and cleaned 40 primary survey responses via Qualtrics to complement the quantitative analysis</li>
                <li>Documented data limitations — reporting inconsistencies and time-lag effects — rather than presenting the numbers as clean</li>
